# 作業中の過集中による身体的負担の検知
## 最終目的
PC作業者が集中して作業を継続することで生じる身体的疲労を検出し、疲労による作業効率の低下を防止すること。
### 目的
疲労による作業効率低下の防止
### 手段
作業中の身体疲労の検出
### 想定する発生状況
長時間の作業による疲労蓄積

## 何をもって疲労と認識するか
### パソコン内部
#### キーボード
- backspaceの頻度
- 入力スピード
- 入力しない時間
####　マウス（疲労という文脈では要らないかも）
- ウィンドウ操作時の移動距離
### パソコン外部のカメラ検知
Webカメラの位置をスクリーンの上に置くことを想定（ノートパソコンであっても同様）
#### 眼関連
- 1分おきの瞬きの回数
- 視線の動き
#### 姿勢
- 姿勢を直した際の動きを検出する

## 仮提案
先ほど挙げたものの実際の作業データを一つずつまずは認識させる。
そのパラメータをそれぞれ出した後に、それをAIによって読み込ませて、何が組み合わされば作業効率が低くなっているかを検出させる。
### 気づき
何をもって作業効率とするのかがまだできていない、
考えられるもので行くと、backspaceやキーボード入力を検出することで、一分間単位で作業がどこまで進んだかを数値化するなどがよさそう？

## 疲労や通常状態を認識するためにクラスタリングを活用してみる
### クラスタリングとは
データ間の類似度に基づいてデータをグループ分けしていく手法のこと
### 読み込ませるデータ
#### パソコン内データ
タイピング速度
作業時間
修正割合　※
スクロールしているか
マウス操作しているか
ウィンドウ切り替え回数
連続入力時間

#### 画像データ

### データの細かい手法（5分単位）
#### パソコン内データ
##### キーボード
###### タイピング速度
5分以内に何回入力が行われたか
###### 連続入力時間
5分の中で規定値を決めて、その数値に達していたら5分追加（持続中）のようにする

###### 修正割合
修正する入力を決めて、その回数を数える(それぞれの処理に重要度も入れたほうがいいかもしれない)
Backspace, Ctrl + Z, delete, Crtl + X, Ctrl + Y, Ctrl + Shift + Z, Ctrl + Backspace

##### 作業時間
単純に計測する（何分以上離れていたらリセットするのは考えた方がよさそう）

##### 他のもの
処理の安定化も加味して、一旦計測しない

###### 瞬き回数
