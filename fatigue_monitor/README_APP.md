# 疲労計測アプリ(ローカル版)

PCの入力(キーボード/マウス)とWebカメラ(MediaPipe Face Landmarker)から、卒論READMEの指標を
**5分単位**で集計してCSVに保存する。解析は `analyze.py`(KMeansクラスタリング)。

## 1. セットアップ
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```
- Python 3.10〜3.12 を推奨。全画面キャリブレーションに標準ライブラリの `tkinter` を使う(Windows/macOSの公式インストーラには同梱。Linuxは `python3-tk` が必要)。
- 初回起動時に顔ランドマークのモデル(約4MB)を `models/` へ自動ダウンロードする。
  失敗したら `config.py` の `MODEL_URL` を手動で保存し `models/face_landmarker.task` に置く。
- **macOS**: 「システム設定 > プライバシーとセキュリティ」で、使うターミナルに
  *入力監視*・*アクセシビリティ*・*カメラ* を許可する。
- **Linux**: X11のみ対応(Wayland上ではキーボード/マウスの全体監視ができない)。

## 2. 実行
引数なしで起動すると、**モード**と**計測対象**を番号で選べる。
```bash
python main.py                                    # 対話で選ぶ
python main.py --mode personal --sensors both     # 個人用・キーボード/マウス+カメラ
python main.py --mode experiment --user P01       # 実験用
python main.py --sensors input                    # キーボード/マウスのみ
python main.py --sensors camera --save-video      # カメラのみ + 映像保存
python main.py --window-sec 60                    # 1分単位(動作確認用)
python main.py --no-preview                       # プレビュー窓なし
```
| 選択 | 内容 |
|---|---|
| `--mode personal` | 自分の計測・動作確認用。質問は最小限。映像は聞かれたとき/`--save-video`のときだけ保存 |
| `--mode experiment` | 被験者用。①被験者ID ②記録内容の説明と**同意の確認**(同意なしは開始しない) ③開始前・終了後の**疲労度(1〜5)** ④メモ。映像は既定で保存(`--no-video`で無効) |
| `--sensors both / camera / input` | 計測対象。使わない側の列はCSVで空欄になる |

- カメラを使う場合、起動すると**全画面の5点キャリブレーション**が始まる(約20〜30秒)。
  1. 準備チェック: 顔の検出・明るさ・カメラとの距離を確認。OKが2秒続くと自動で次へ(Enter: すぐ開始 / Esc: スキップ)。
  2. 画面の点(中央 → 左上 → 右上 → 右下 → 左下)を、頭を動かさず目だけで見る。
  - ここで決まるもの: 眼の開き具合の基準、**正面を向いたときの顔の向き・位置・大きさ**。各点の生データは `meta.json` の `calibration` に保存される。
  - Escで中止・失敗した場合や `--no-calibration` のときは、従来どおり**起動直後の20秒**で自動的に基準を決める(その間は目を普通に開けて画面を見る)。
  - 主に作業する画面(カメラが付いている画面)で行うこと。外付けモニターで作業する場合は、そのモニターに表示して行う。
- カメラは画面上部、顔が正面から写る位置に置く。プレビュー窓の黄色い点が目・顔に乗っているか確認。
- 終了はプレビュー窓で `q`、またはターミナルで `Ctrl+C`(**この正常終了のときに映像ファイルが完成する**)。1分以上たまっていれば最後の区間もCSVに保存する。
- 実験モードの終了後の質問(疲労度・メモ)は、計測を止めてから聞くので、入力が計測に混ざらない。

### 出力(すべて `data/`)
| ファイル | 内容 |
|---|---|
| `<ID>_<日時>.csv` | 1行 = 1区間(既定5分)の集計値 |
| `<ID>_<日時>_meta.json` | モード、計測対象、開始/終了時刻、**使った設定値(config)**、**キャリブレーション結果(各点の生データ)**、疲労度(前/後)、メモ、映像ファイル名 |
| `<ID>_<日時>.mp4` | 映像(保存したときのみ。mp4が使えない環境では .avi) |

### 映像について
- 容量を抑えるため、保存時は縦横を半分(640×360)に縮小し、日時を映像に焼き込む(CSVの区間と突き合わせるため)。目安は10分あたり数十MB〜。`config.py` の `VIDEO_SCALE` / `VIDEO_TIMESTAMP` で変更できる。
- 映像は**終了時に完成するファイル**。ターミナルを閉じる・強制終了・PCのシャットダウンだと、再生できなくなることがある。
- 処理が遅れても、実時間に合うようフレームを補って時間軸を保つ。

## 3. 解析
```bash
python analyze.py              # k=2〜5をシルエット係数で選ぶ
python analyze.py --k 3
python analyze.py --no-per-user
```
被験者ごとに標準化 → KMeans → 各クラスタの特徴を表示し、`results/` にラベル付きCSVとPCA散布図を保存。

## 4. プライバシー(被験者への説明用)
- 入力した**文字の内容は記録しない**(回数・種類・時刻のみ)。ウィンドウのタイトルも記録しない。
- 映像を保存しない設定(既定の個人モード)では、**映像・画像は残らない**(フレームごとの数値を集計するだけ)。
- **映像を保存する設定では、顔が写る動画が `data/` に残る**。これは個人情報にあたるので、同意書、保存場所・保存期間・削除方法の取り決めを、大学や指導教員のルール(研究倫理審査の要否を含む)に沿って確認しておくこと。
- 実験モードでは、記録内容を画面に表示して同意を確認してから開始する。

## 5. 出力列と定義
| 列 | 内容 |
|---|---|
| `continuous_work_min` | 連続作業時間(分)。区間のうち操作した秒の割合(`active_ratio`)が `WORK_ACTIVE_RATIO`(0.3)以上の区間が続く間、区間の長さを加算。下回る区間があるとリセット(休憩扱い) |
| `active_ratio` | 区間のうち、キーボードまたはマウスを操作していた秒の割合 |
| `typing_count`, `typing_per_min` | キー入力回数(修飾キー単体・長押しのオートリピートは除く) |
| `correction_*` | 修正入力(Backspace, Delete, Ctrl+Z/X/Y, Ctrl+Shift+Z, Ctrl+Backspace)。重みは `config.py` で変更。`correction_ratio` = 重み付き修正数 / 入力回数 |
| `net_input` | 入力回数 − 修正回数(作業量の粗い目安) |
| `max_streak_sec` | 参考値: 間隔が `STREAK_GAP_SEC`(3秒)以内で続いた入力の最長継続秒数(解析では使わない) |
| `key_idle_total_sec`, `key_max_idle_sec` | 入力しない時間(5秒以上の空白の合計 / 最長の空白) |
| `scroll_count` | スクロールイベント数 |
| `mouse_*` | クリック数、移動距離(px)、マウスを動かしていた秒の割合 |
| `window_switch_count` | ウィンドウ切り替え回数。Windowsは前面ウィンドウの変化を0.2秒ごとに監視し、0.5秒以上前面にあった別ウィンドウを数える(Alt+Tab・タスクバー・クリックすべて対象、タイトルは記録しない)。Windows以外は Alt+Tab / Cmd+Tab |
| `face_detected_ratio`, `face_sec` | 顔を検出できたフレームの割合 / 検出できていた秒数。`MIN_FACE_RATIO` 未満の区間はカメラ指標が空欄 |
| `pose_valid_ratio`, `obs_sec` | 顔の向きが基準から大きく外れていないフレームの割合 / その秒数。**瞬き・眼の開き・視線は、この有効なフレームだけで集計**する。`obs_sec` が `MIN_EYE_OBS_SEC`(5秒)未満の区間は、これらが空欄 |
| `head_yaw_mean`, `head_pitch_mean`, `head_roll_mean` | 顔の向きの、基準(正面)からの差の平均(度)。左右・上下・傾き。符号は目安 |
| `blink_count`, `blink_per_min` | 瞬き回数(開眼度が基準値×0.65を下回り、0.8秒以内に戻ったもの) |
| `eye_open_mean`, `eye_open_rel` | 眼の開き具合(上下まぶたの距離÷目の幅、瞬き中を除く平均)と、キャリブレーション基準に対する比 |
| `fixation_ratio`, `max_fixation_sec` | 視線の一点集中: 虹彩中心が基準点から半径内に1秒以上留まった時間の割合 / 最長滞在 |
| `gaze_shift_per_min` | 視線が基準点から半径外に動いた回数(1分あたり) |
| `posture_change_count` | 顔の中心y座標が基準から4%以上動いた回数(3秒のクールダウン付き) |
| `posture_max_hold_sec` | 姿勢を直さずに維持した最長時間 |
| `face_y_mean`, `face_width_mean` | 顔の高さ位置・顔の大きさ(猫背や画面への近さの目安) |
| `face_y_dev`, `face_width_rel` | キャリブレーションの正面に対する、顔の高さのずれ / 顔の大きさの比(姿勢の変化の目安。向きに関係なく集計) |

## 6. 解釈を置いた点・既知の限界
- READMEの「連続入力時間」は「連続作業時間」(`continuous_work_min`)に置き換えた。「5分の中で規定値に達したら5分追加(持続中)」を、`WORK_ACTIVE_RATIO` を規定値とする区間単位の加算として実装している。
- 視線は目の幅を1とした虹彩の相対位置で見ているだけで、画面上の注視点は求めていない。
- キャリブレーション中(最初の20秒)は瞬き等を数えない。比率系の指標は実際に観測できた秒数で割っている(`obs_sec`)。
- 閾値(`config.py`)はすべて初期値。実測しながら調整する。
- `analyze.py` では `continuous_work_min` が時間経過だけでクラスタを分けてしまうことがある。結果が「前半/後半」になるなら特徴量から外して試す。
- クラスタリングは正解ラベルがないため、作業後の自己申告(疲労度1〜5など)を別に記録しておくと、結果の妥当性を後から検証しやすい。
- **顔の向き(方式A)**: 向きが大きく外れたフレームを、瞬き・眼の開き・視線の集計から**除外**する。値の**補正はしていない**(`eye_open_rel` は生の比のまま)。基準は正面(中央の点)で、閾値は `YAW_MAX_DEG` / `PITCH_MAX_DEG` / `ROLL_MAX_DEG`(20/20/25度)。下を向いて作業する時間が長い人は除外が増えるので、`pose_valid_ratio` で確認する。向きに応じた補正は、`meta.json` の各点のデータを使って後から解析で試せる。
- 向きはランドマークの3D座標から求めた目安の値で、精度は限定的(実測で閾値を調整する)。
- 眼の開き具合の基準は、5点すべてのデータの中央値。点を見ている間は視線方向が変わるため、中央だけの値より少し小さくなる。
